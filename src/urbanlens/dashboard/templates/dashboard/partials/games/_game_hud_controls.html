{% comment %} Shared HUD controls: rail drawer toggle, focus mode, true fullscreen. Include at the end of a game HUD's trailing group. No ids - game-shell.ts binds these purely by data-attribute, scoped to the shell element it was constructed with, so three games can render them without colliding. The focus control toggles in both directions and persists its state under `ul_game_immersive`, so a one-way exit would strand the player in the plain scrolling layout with nothing to press to get back. {% endcomment %}
